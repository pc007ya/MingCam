01 / RECORDING

螢幕錄影與系統內錄

直接透過系統原生擷取 API 錄製高畫質影片與數位音訊，完全免裝第三方虛擬音效卡。

  • 全螢幕、矩形穿透框、指定單一視窗錄製
  • 30 / 60 FPS H.264 `.mp4`，無時長與浮水印限制
  • 純音訊內錄 `.m4a`（AAC 48kHz / 192kbps）
  • 無縫暫停與繼續，自動校正時間軸
02 / SNIPASTE PIN

框選截圖與懸浮貼圖

凍結畫面後精準框選，並可將任意參考圖、報表或文字釘選於所有視窗最上層。

  • 游標像素放大鏡，即時顯示座標與 HEX / RGB 色碼
  • 支援截圖、剪貼簿圖片與剪貼簿文字直接貼圖
  • 滑鼠滾輪平滑縮放（25% – 400%）
  • 組合鍵 + 滾輪調整透明度（20% – 100%）
03 / ANNOTATION

PicPick 風格即時標註

截圖當下立即畫重點、打馬賽克與標記操作步驟，完成後一鍵複製、貼圖或存檔。

  • 內建 9 種工具：矩形、橢圓、箭頭、直線、畫筆等
  • 螢光筆、敏感資訊馬賽克遮罩與文字標註
  • 自動遞增步驟序號章（① ② ③）
  • 背景全域快捷鍵，視窗縮小也能隨時呼出
