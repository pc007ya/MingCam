# MingCam — macOS 原生螢幕錄影・內錄音訊・截圖貼圖與標註工具

**MingCam** 是一款使用 SwiftUI 與 Apple 原生 `ScreenCaptureKit` / `AVFoundation` 從零打造的 macOS 全能螢幕擷取工具，結合了：
- 🎬 **高畫質螢幕錄影與系統音訊內錄**（完全無時長限制、無浮水印）
- 📌 **Snipaste 風格區域截圖與螢幕懸浮貼圖**
- ✏️ **PicPick 風格即時標註工具列與像素放大鏡取色器**

---

## ✨ 功能特色

### 1. 螢幕錄影與音訊內錄
- **全螢幕錄製**：支援多顯示器高解析度 30 / 60 FPS H.264 `.mp4` 錄製。
- **矩形區域錄製**：可拖曳、可縮放的綠色中空穿透框選範圍，錄影時自動轉為紅框且點擊穿透、不錄入邊框本身。
- **指定視窗錄製**：鎖定單一應用程式視窗進行獨立錄製。
- **純音訊內錄 (`.m4a`)**：直接擷取 macOS 系統內部播放的高音質數位音訊（AAC 48kHz / 192kbps）與麥克風聲音。
- **無縫暫停／繼續**：暫停期間自動校正時間軸，不留空白片段。

### 2. Snipaste 風格截圖與螢幕貼圖
- **框選截圖 (`⇧⌘S` / `F1`)**：凍結當前畫面並顯示游標放大鏡、座標與即時 `HEX / RGB` 色碼（按 `C` 鍵即可複製色碼）。
- **螢幕懸浮貼圖 (`⇧⌘V` / `F3`)**：
  - 將截圖、剪貼簿圖片、或剪貼簿文字直接釘選懸浮於螢幕最上層。
  - **滑鼠滾輪**：平滑縮放貼圖大小（`25% ~ 400%`）。
  - **`Option (⌥)` + 滑鼠滾輪**：調整貼圖透明度（`20% ~ 100%`）。
  - **雙擊貼圖**或透過右鍵選單即可關閉、複製或另存 PNG。

### 3. PicPick 風格即時標註工具
- 內建 **9 種標註工具**：矩形、橢圓、箭頭、直線、畫筆、螢光筆、馬賽克遮罩、步驟序號章（`① ② ③` 自動遞增）、文字標註。
- 支援多色調色盤、3 段筆觸粗細、`⌘Z` 復原與一鍵清空。

### 4. 背景全域快捷鍵
- 採用 macOS `Carbon` 全域熱鍵機制，即使視窗縮小或在背景執行，也能隨時透過快捷鍵觸發截圖、貼圖、取色或開始/停止錄影，並支援在介面中自訂按鍵組合。

## 🛠 編譯與執行

### 系統需求
- macOS 14.0 (Sonoma) 或以上版本（Apple Silicon / Intel）
- Xcode 或 Xcode Command Line Tools

### 一鍵編譯 `.app`
```bash
chmod +x build_app.sh
./build_app.sh
open ../MingCam.app
```

首次執行錄影或截圖時，請於 **「系統設定 > 隱私權與安全性 > 螢幕與系統音訊錄製」** 中勾選允許 `MingCam`。
